# aeph

A minimal TUI markdown editor with task management.

## Install

```bash
npm install -g aeph
```

## Usage

```bash
ae              # Open editor
ae file.md      # Open specific file
```

## Features

- 9 document slots
- Task management (`- [ ]` / `- [x]`)
- Smart list continuation
- Tab/Shift+Tab for indentation
- Auto-save
- Markdown syntax highlighting

## Keyboard Shortcuts

| Key | Action |
|-----|--------|
| Ctrl+S | Save |
| Ctrl+Q | Quit |
| Ctrl+T | Toggle task |
| Ctrl+N | New task |
| Ctrl+O | Open document picker |
| Ctrl+H | Help |
| Tab | Indent list |
| Shift+Tab | Unindent list |
